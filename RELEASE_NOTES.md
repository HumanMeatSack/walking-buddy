# Walking Buddy v0.1.0 (Public Beta)

The first public release of Walking Buddy, a tiny draggable desktop companion for macOS.

## Included

- Eight original characters: Halloween Ghost, Santa & Sleigh, Spring Bunny, Wizard Cat, Tiny Dragon, UFO Alien, Snowman, and Beach Crab
- Automatic seasonal character selection or manual character selection
- Five character sizes and four walking speeds
- Left-to-right walking, gentle bobbing, drag-and-drop positioning, pause, and reset controls
- Menu-bar-free desktop companion behavior

## Installation note

This beta is ad-hoc signed but not Apple-notarized. After downloading and unzipping it, you may need to Control-click **Walking Buddy.app**, choose **Open**, and confirm once.

This public edition intentionally contains no third-party game or branded character artwork.
