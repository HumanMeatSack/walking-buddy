# Walking Buddy v0.2.0 (Windows Beta)

Walking Buddy now supports both macOS and 64-bit Windows 10/11.

## New in v0.2.0

- Native transparent, always-on-top Windows companion
- Self-contained Windows executable with no separate .NET installation needed
- Windows system-tray controls for characters, sizes, speeds, pause, reset, and quit
- Drag-and-drop positioning that resumes walking in the release direction
- Preferences remembered between launches
- Automated builds for both macOS and Windows

## Included characters

Halloween Ghost, Santa & Sleigh, Spring Bunny, Wizard Cat, Tiny Dragon, UFO
Alien, Snowman, and Beach Crab.

## Installation notes

The Windows beta is not code-signed, so Windows may display an Unknown
Publisher or SmartScreen notice. The macOS beta is ad-hoc signed but not
Apple-notarized. If you do not trust a binary download, build it from the
public source instead.

This public edition intentionally contains no third-party game or branded
character artwork.
